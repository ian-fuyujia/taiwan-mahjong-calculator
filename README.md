# 台灣麻將算台機

四個人共用一台手機的台灣 16 張麻將工具。它可以算台數、算錢，並累計四家輸贏。

**使用連結：** https://ian-fuyujia.github.io/taiwan-mahjong-calculator/

## 功能

- 勾選牌型，自動加總台數。互斥的牌型會自動取消。
- 選胡牌者、放槍者，算出每家要付的金額。
- 累計四家輸贏。莊家和連莊數會自動更新。
- 可以復原上一把、記流局、調整每個台型的台數。

## 注意事項

- 預設台數是常見的 16 張算法，不是官方標準。請先對照自己牌桌的規則。
- 輸贏紀錄存在手機瀏覽器裡。清除瀏覽資料後會消失。
- 不支援一炮多響，也不會自動追蹤圈風。

## 檔案

整個工具只有一個檔案：`index.html`。沒有建置步驟，也沒有相依套件。
